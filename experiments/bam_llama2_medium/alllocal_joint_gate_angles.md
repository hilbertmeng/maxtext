# 两门联合状态下的读写地址与内容夹角

结论：读低写高与读高写高的地址夹角分布都围绕90°，差异较小；读高写高的读出内容与总写入内容明显更同向。扣除写入中的LocalO后，内容差异大幅缩小，说明主要是LocalO自身的加入改变合成向量方向，而不是其余三项普遍转向对齐。

## 测前下注与定义

测前下注：两组地址角度差异小；读高写高的内容角度更小，读低写高更分散、偏向正交。实测前已在任务中记录，未根据结果更换预测。

模型 `BamMediumIndependentLLFQKConcatStaticLocalVOSharedC8IndependentGatesK48QK48MLPPerLayerAllLocal`，checkpoint13500；发现集0–31选L3–L16读写Spearman≤−0.3的87头，评估32–127共96条。无读门覆盖筛选。主阈值两门0.1，同时保留0.05、0.2。低开度不等于零。

地址角度：LocalO在C8压缩M上的读键，经abs_v_cache_projection映射到完整M的address坐标，再与实际归一化后的P_loc写地址求夹角。沿用捕获字段key_cos。

内容角度：实际LocalO读出内容o，与四部分合成写入向量s=a+b+c+o的夹角。此配置的写数据RMS归一化、写门均为正标量，不改变方向；LocalO读门也是正标量。只比较BAM注入及写入的48维data空间，不是W_O后的残差流。内容角度利用完整Gram重构：cos(o,s)=(G03+G13+G23+G33)/sqrt(G33·ΣijGij)。

控制角度：cos(o,a+b+c)，用于区分“总写入包含LocalO导致自然对齐”和“其他三项也更对齐”。这不是先前字段content_cos；该字段比较LocalO写入与写地址处旧M内容，两者不能混用。真零向量角度记为缺失，本次87头有效位置没有因此缺失。

## 四种状态的完整分布摘要

以下角度单位为度，P10 / P50 / P90是位置合并的精确分位数，不是各头分位数平均。完整CDF/1°直方图另存。

| 状态 | 位置数 | 地址角度P10/P50/P90 | 内容角度P10/P50/P90 | 内容角度>90° |
|---|---:|---:|---:|---:|
| 读高写低 | 756,417 | 76.1 / 90.9 / 108.4 | 15.7 / 37.3 / 64.4 | 0.41% |
| 读低写高 | 13,127,106 | 76.7 / 93.6 / 111.1 | 42.3 / 68.7 / 91.8 | 12.03% |
| 两门低 | 2,210,449 | 81.0 / 95.6 / 111.5 | 45.4 / 68.8 / 88.7 | 8.44% |
| 两门高 | 1,010,924 | 76.5 / 90.6 / 105.7 | 17.9 / 38.0 / 64.8 | 0.82% |

读高写高的内容夹角P10/P90为17.9°/64.8°，读低写高为42.3°/91.8°；前者分布整体更小。读门高的两组内容中位数37.3°、38.0°几乎一样；读门低的两组68.8°、68.7°也几乎一样。合并分布上内容对齐主要随读门状态区分，不能把它单独归给写门高低。

地址没有呈现从明显错开到明显对准的切换。读低写高与读高写高的地址钝角比例分别60.83%、52.07%，中心仍在近正交区间。内容更同向不意味着写回同一地址，也不自动意味着对旧M内容的加强。

## 同头比较与LocalO自身贡献

为防止两组由不同头构成，只比较两种状态各有≥256有效位置且覆盖≥8评估序列的69个头。每头先求状态内平均角度，再对头等权；CI以96条序列为簇bootstrap4000次，固定所选头。

| 读高写高 − 读低写高 | 同头平均差 | 95%序列bootstrap区间 | 角度变小/变大头数 |
|---|---:|---:|---:|
| 地址角度 | -2.00° | [-2.16°, -1.84°] | 43/26 |
| 读出 vs 总写入 | -29.61° | [-30.13°, -29.05°] | 68/1 |
| 读出 vs 扣除LocalO后的写入 | -1.75° | [-2.04°, -1.44°] | 40/29 |

68/69头总内容角度变小，方向很普遍；扣除LocalO后只有40/69头变小，平均差从29.61°缩至1.75°。这是构成对照，不是下游loss消融，也不能把两种角度之差线性解释为百分比因果贡献。

一个必须指出的混合效应：扣除LocalO后，位置合并的两组中位数分别为读低写高75.1°、读高写高83.1°，看似后者更不对齐；但上述同头等权平均差为−1.75°。不同头的组内位置权重和统计量都发生变化，不能把总体中位数差宣称为普遍的头内规律。

0.05阈值下，两组地址中位数93.8°/92.6°、总内容70.3°/51.9°；0.2阈值下，地址93.0°/85.7°、总内容67.1°/28.2°。因此“内容差异远大于地址差异”稳定，但地址差异不是恒定为零，极高读门子集的地址也更偏锐角。
